# Employee Management System
## Problem Statement
Managing employee information manually can make storing, searching, updating, and organizing employee records difficult. A centralized system is needed to maintain employee information and provide basic department and salary management.
The proposed Employee Management System provides a simple command-line solution using Java and SQL to manage employee records efficiently.
## Scope of the Project
The project covers:
* Adding, viewing, searching, updating, and deleting employee records
* Managing department information
* Assigning employees to departments
* Viewing employees according to departments
* Performing basic salary analysis
* Storing employee and department data in an SQL database
* Providing input validation and error handling
## Target Users
The system is intended for:
* HR staff
* Administrators
* Small organizations
## High-Level Features
### Employee Management
* Add employee
* View all employees
* Search employee by ID or name
* Update employee details
* Delete employee
* View employees by department
### Department Management
* Add department
* View departments
* View employees belonging to a department
### Salary Management
* Calculate average salary
* Find highest salary
* Find lowest salary
* Generate department-wise salary summary
### Supporting Features
* Input validation
* Error handling
* SQL database storage
* JDBC database connectivity
